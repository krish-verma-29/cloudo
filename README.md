# cloudo
A smart and minimal weather application built with Flutter, Firebase, and WeatherAPI. Features include real-time weather updates, forecasts, and AI assistance.

## Setup
1. Clone the repo
2. Run `flutter pub get`
3. Get a WeatherAPI key from weatherapi.com
4. Run: `flutter run --dart-define=WEATHER_API_KEY=your_key`
